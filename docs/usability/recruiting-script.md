# recruiting-script.md — Roteiro Recrutamento Mani

## Screener (pré-seleção)

### Obrigatórios (mínimo 3 de 3)
- [ ] Nail designer autônoma (> 6 meses de atuação)
- [ ] Gerencia agenda/clientes via WhatsApp + papel (não usa SaaS de salão)
- [ ] Possui smartphone Android ou iOS (uso diário)

### Desejáveis (mínimo 2 de 3)
- [ ] Atende em casa/stúdio próprio (não dependente de salão alugado)
- [ ] Faz alongamento/manutenção (serviços complexos com anamnese)
- [ ] Já teve cliente que não compareceu (no-show)

### Exclusão (qualquer um = fora)
- [ ] Usa algum SaaS de agendamento (Trinks, Belasis, Booksy, etc.)
- [ ] Trabalha apenas como CLT em salão (não autônoma)
- [ ] Não tem smartphone

### Fluxo LGPD (Recrutamento)

1. Contato inicial → coleta nome + telefone + perfil profissional
2. Screener → valida critérios (obrigatórios + desejáveis + exclusão)
3. Confirmação → coleta disponibilidade + contato
4. Sessão → assinatura consentimento (LGPD Art. 7º, incisos I e IX)
5. Pagamento → Pix na hora (não coleta dados bancários)
6. Retenção → dados excluídos após 12 meses ou mediante revogação
