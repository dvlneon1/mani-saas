# moderator-guide.md — Script Moderador (90 min)

## Setup Pré-Sessão (30 min antes)

- [ ] Celular carregado + carregador por perto
- [ ] Expo Go instalado no device da participante
- [ ] QR code do protótipo pronto (tunnel)
- [ ] Gravadora de tela testada (built-in iOS/Android)
- [ ] Consent form impresso/digital pronto
- [ ] Observation sheet aberta no notebook do moderador
- [ ] Backup: link Figma Mirror caso Expo falhe

---

## Script (90 min)

### 0. Boas-vindas + Consentimento (10 min)

**Falar:**
> "Oi {{nome}}, bem-vinda! Obrigada por participar. Hoje vamos testar um app para nail designers chamado Mani.

> Importante: **não estamos testando você, estamos testando o app**. Não tem resposta certa ou errada. Se algo não funcionar, é problema do app, não seu.

> Você vai navegar pelo app no seu celular fazendo 5 tarefas. Enquanto faz, fale em voz alta: o que está pensando, o que espera, o que te deixa em dúvida.

> Vamos gravar sua tela e áudio para análise posterior. Seus dados são sigilosos (LGPD). No final você recebe R$ 150 via Pix.

> Pode começar quando quiser."

**Ações:**
- Assinar consent form
- Explicar gravação tela + áudio
- Perguntar se tem dúvidas
- Iniciar gravação de tela

---

### 1. Contexto Demográfico (5 min)

**Perguntas:**
1. Há quanto tempo atua como nail designer?
2. Onde atende (casa, estúdio, salão alugado)?
3. Como gerencia agenda/clientes hoje? (WhatsApp, papel, agenda, caderno)
4. Já usou algum app de salão? Qual? Por que parou/de não usa?
5. O que mais te dá trabalho na gestão hoje?

**Anotar no observation sheet.**

---

### 2. Tarefas 1–5 (60 min = ~12 min cada)

**Para cada tarefa:**
1. Ler cenário do cartão impresso
2. "Pode começar quando quiser"
3. Observar + anotar (não ajudar a menos que trave total > 2 min)
4. Se travar: "Tente do seu jeito. O que você esperava encontrar aqui?"
5. Pós-tarefa: "Quão fácil foi, de 1 a 5? O que travou? O que esperava?"

#### Tarefa 1: Onboarding Completo
**Cenário:** "Você acaba de baixar o Mani. Quer criar seu perfil profissional, cadastrar 3 serviços (Alongamento Fibra, Manutenção, Esmaltação), cadastrar sua primeira cliente e agendá-la para amanhã às 10h."
**Tempo alvo:** < 8 min
**Passos críticos:** Perfil → Serviços → Cliente → Agendamento → Confirmação

#### Tarefa 2: Agendamento Recorrente + Check-in/out
**Cenário:** "Sua cliente Maria faz manutenção a cada 2 semanas. Agende 3 manutenções dela (segundas-feiras, manhã) para as próximas 6 semanas. Na segunda-feira que vem, quando ela chegar, faça check-in e depois check-out."
**Tempo alvo:** < 5 min
**Passos críticos:** Agenda → Novo → Recorrência → Confirmar 3 datas → Check-in → Check-out

#### Tarefa 3: Anamnese Digital via WhatsApp
**Cenário:** "Uma cliente nova precisa preencher a anamnese. Envie o link por WhatsApp. Quando ela terminar, você recebe notificação. Abra o PDF e veja a assinatura."
**Tempo alvo:** < 6 min (lado profissional)
**Passos críticos:** Cliente sem anamnese → Enviar WhatsApp → Aguardar notificação → Abrir PDF → Verificar assinatura

#### Tarefa 4: Upload Galeria + Tags + Portfolio
**Cenário:** "Você terminou uma extensão de fibra na Maria. Quer subir 5 fotos (antes, durante, depois), colocar tags (Fibra, Nude, Risqué) e marcar como público no portfolio."
**Tempo alvo:** < 4 min
**Passos críticos:** Galeria → + Fotos → Selecionar fase → Tags → Portfolio ON → Enviar → Compartilhar

#### Tarefa 5: Financeiro Parcelado + DRE
**Cenário:** "Maria pagou R$ 350 de alongamento (entrada R$ 150 + 2 parcelas de R$ 100). Registre esse lançamento e depois veja o DRE do mês para conferir o lucro."
**Tempo alvo:** < 4 min
**Passos críticos:** Financeiro → + Lançamento → Parcelado (entrada + 2x) → PIX → Salvar → Relatórios → DRE

---

### 3. Debrief + Questionários (15 min)

**SUS (10 itens):** Aplicar questionário padrão.

**NPS:** "De 0 a 10, quanto você recomendaria o Mani para uma colega nail designer? Por que essa nota?"

**Debrief (ver debrief-guide.md):**
- O que mais gostou?
- O que mudaria?
- O que falta que você faz hoje?
- Quanto pagaria por mês por esse app?

---

### 4. Encerramento (5 min)

**Falar:**
> "Obrigada {{nome}}! Suas respostas vão ajudar muito a melhorar o app. O pagamento de R$ 150 vai por Pix agora."

**Ações:**
- Pix R$ 150 (mostrar confirmação na tela)
- Agradecer
- Pedir contato para dúvidas futuras
- Parar gravação

---

## Regras do Moderador

**FAZER:**
- Deixar a participante explorar livremente
- Fazer perguntas abertas ("O que você espera aqui?", "O que esse botão faz?")
- Anotar timestamps de dificuldades
- Manter neutralidade (não defender o app)

**NÃO FAZER:**
- Não ensinar como usar o app
- Não dizer "clique aqui"
- Não liderar respostas ("Esse botão é ótimo, né?")
- Não ajudar antes de 2 min travada
