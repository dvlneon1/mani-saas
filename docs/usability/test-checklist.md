# test-checklist.md — Checklist Device e Protocolo

---

## Antes da Sessão (30 min antes)

- [ ] Celular do moderador carregado + carregador
- [ ] Expo Go instalado no device da participante
- [ ] QR code do protótipo gerado (npx expo start --tunnel)
- [ ] Link Figma Mirror como backup (caso Expo falhe)
- [ ] Consent form impresso ou digital pronto
- [ ] Observation sheet aberta no notebook
- [ ] Cartões de cenário impressos (5 tarefas)
- [ ] Caneta para anotações rápidas
- [ ] Pix configurado (R$ 150)
- [ ] Câmera/gravação de tela testada
- [ ] Fones de ouvido (opcional, para áudio claro)

---

## Device Checklist iOS

- [ ] iOS 15+
- [ ] Espaço armazenamento > 2 GB
- [ ] Bateria > 50% (ou carregador por perto)
- [ ] Expo Go instalado na App Store
- [ ] Permissão câmera (para simulação galeria/fotos)
- [ ] Modo avião DESLIGADO (precisa de internet para Expo tunnel)
- [ ] Não perturbe DESLIGADO

---

## Device Checklist Android

- [ ] Android 9+
- [ ] Espaço armazenamento > 2 GB
- [ ] Bateria > 50% (ou carregador por perto)
- [ ] Expo Go instalado na Play Store
- [ ] Permissão câmera e armazenamento
- [ ] Modo avião DESLIGADO
- [ ] Não perturbe DESLIGADO
- [ ] Otimização de bateria desligada para Expo Go

---

## Durante a Sessão

- [ ] Iniciar gravação de tela antes de explicar
- [ ] Assinar consent form
- [ ] Explicar: "testamos o app, não você"
- [ ] Ler cada cenário do cartão impresso
- [ ] Deixar participante explorar livremente
- [ ] Não ajudar antes de 2 min travada
- [ ] Anotar timestamps de dificuldades
- [ ] Aplicar SUS + NPS + debrief ao final
- [ ] Pagar R$ 150 Pix
- [ ] Parar gravação

---

## Após a Sessão

- [ ] Salvar gravação (nome: sessao_N_data.mp4)
- [ ] Preencher observation sheet completo
- [ ] Calcular SUS score
- [ ] Calcular NPS
- [ ] Backup gravação + observation sheet no Drive criptografado
- [ ] Excluir dados do participante do device de teste (se usou device do moderador)

---

## Protocolo Pós-Sessão (mesmo dia)

1. Consolidar observation sheet
2. Calcular métricas agregadas (task success rate, tempo médio, erro médio)
3. Anotar top 3 problemas e top 3 sucessos
4. Enviar agradecimento + comprovante Pix para participante
5. Agendar próxima sessão (se houver)

---

## Backup Figma Mirror (se Expo falhar)

1. Abrir link Figma Mirror no navegador do celular
2. Navegar pelos frames estáticos (sem interatividade)
3. Moderador simula interações ("se você clicasse aqui, o que aconteceria?")
4. Anotar limitações do método estático no observation sheet
